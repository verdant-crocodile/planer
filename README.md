# dopamine planner

Приложение для распорядка дня по часам. После первой установки работает без интернета.

## Как установить на iPad

Приложению нужен адрес в интернете, но только один раз, для установки. Проще всего бесплатно разместить его на GitHub Pages.

1. Зарегистрируйся на github.com.
2. Создай новый публичный репозиторий, например `planer`.
3. Нажми «Add file → Upload files» и перетащи все файлы из этой папки: `index.html`, `sw.js`, `manifest.webmanifest` и три картинки `.png`. Нажми «Commit changes».
4. Открой Settings → Pages. В поле Source выбери «Deploy from a branch», ветку `main` и папку `/ (root)`, затем нажми Save.
5. Через минуту-две появится адрес вида `https://<твой-логин>.github.io/planer/`.
6. Открой этот адрес на iPad именно в **Safari**.
7. Нажми «Поделиться → На экран „Домой“». На рабочем столе появится иконка «planner».
8. Один раз запусти приложение с иконки при включённом интернете. Дальше оно будет открываться и без сети.

## Где хранятся данные

Все блоки, привычки и задачи хранятся только на этом iPad, внутри приложения. Синхронизации между устройствами нет.

Время от времени делай резервную копию: кнопка «⋯» → «Скачать файл» или «Скопировать в буфер». Из этой же копии можно восстановить данные на другом устройстве.

Если удалить иконку с рабочего стола, вместе с ней удалятся и данные. Перед удалением сделай копию.

## Как обновить приложение

Загрузи новый `index.html` в репозиторий поверх старого, а в `sw.js` увеличь номер версии (`planer-v1` → `planer-v2`). При следующем запуске с интернетом приложение обновится. Данные при этом сохранятся.
